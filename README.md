# 세모바 (Semoba) — 세상 모든 바코드

> 바코드와 QR을 찍으면 **제품 정보를 한글로 설명**하고, QR 링크는 **열기 전에 위험도부터 알려 주는** 메신저형 PWA.

**상태:** 설계 완료 · 구현 준비 중 (Phase 1 MVP). 아직 실행 가능한 코드는 없습니다.

---

## 무엇을 하나요

| 기능 | 설명 |
| --- | --- |
| 🌏 **제품 정보 요약** | 해외·국내 상품의 바코드를 스캔하면 제품명·성분·사용법을 한글로 번역·요약합니다. 가격·구매처는 제품명 기반 구글 검색 링크로 연결합니다. 데이터에 없는 정보는 지어내지 않고 "정보 없음"으로 안내합니다. |
| 🛡️ **큐싱 안심 방패** | URL이 담긴 QR을 스캔해도 바로 열지 않고, 보안 DB 조회와 URL 규칙 분석으로 위험도(안전 / 주의 / 위험)를 먼저 보여 줍니다. "안전"은 보증이 아니라 **알려진 위협을 확인하지 못했다**는 뜻입니다. |
| 🎨 **맞춤 QR 생성** (부가) | 채팅창에 "이 주소 네이비 톤으로 QR 만들어줘"라고 쓰면, 링크를 검증한 뒤 색상을 입힌 QR(SVG)을 만들어 줍니다. 위험·주의 링크는 만들지 않습니다. |

별도 앱 설치 없이 브라우저에서 동작하는 PWA이며, 채팅창 아래 📷 버튼으로 바텀 시트 스캐너를 엽니다.

## 동작 방식

```
스캔(카메라) ─▶ 코드가 유형 분기 ─▶ 바코드 → 제품 조회 ──▶ 제품 카드 (facts 즉시, 한글 서술은 이어서)
                                  └ URL QR  → 보안 판정 ──▶ 보안 카드 (코드 템플릿 문구)
채팅 ──────────▶ 코드가 키워드로 도구 선택 ─▶ 링크 검사 / QR 생성, 그 밖에는 엑사원 답변
```

**핵심 원칙: 코드가 판정하고, AI는 설명한다.**

- 바코드·QR 디코딩, 제품·보안 조회, **보안 등급 판정**, QR 생성은 모두 코드(결정론적)가 합니다.
- LG AI연구원 **K-EXAONE 2.5**는 **제품 서술(한글 요약·번역)과 채팅 답변**만 맡습니다. 보안 카드와 QR 카드의 문구는 코드 템플릿이고, AI는 보안 등급을 바꿀 수 없습니다.
- 그래서 AI 호출이 한도에 걸리거나 실패해도 **스캔·보안 검증·QR 생성은 계속 동작**합니다.

## 아키텍처

SvelteKit + Cloudflare 풀스택 서버리스.

| 계층 | 기술 | 역할 |
| --- | --- | --- |
| 프론트엔드 | SvelteKit 5, PWA | 채팅 UI, 스캐너(`BarcodeDetector` + `zxing-wasm` 폴백) |
| 서버 | Cloudflare Workers | 스캔 분기, 외부 조회, 보안 판정, QR 생성, 엑사원 호출 |
| 데이터베이스 | Cloudflare D1 | 세션·메시지(카드 JSON)·AI 사용량 카운터·서술 캐시 |
| 오브젝트 스토리지 | Cloudflare R2 | 생성된 QR SVG |
| 캐시 | Cloudflare KV | 바코드·보안·도메인 연령 조회 캐시 |
| AI | K-EXAONE 2.5 | 제품 서술, 채팅 (Tool Calling) |
| 외부 데이터 | Open Food Facts, UPCitemdb, Google Safe Browsing, URLhaus, RDAP | 제품 정보, 위협 평판, 도메인 연령 |

## 지켜야 할 제약

- **디자인:** Navy(`#001F3F`) + Sky Blue(`#00BFFF`). **빨간색·초록색은 사용하지 않습니다.** 위험도는 앰버·보라 계열과 아이콘으로 표현합니다.
- **AI 한도:** 제공자 한도가 초당 1회·분당 60회라, 호출 간격 게이트와 사용자별 한도, 캐시·비동기 서술로 통제합니다.
- **개인정보:** 외부 조회와 저장에는 URL의 쿼리·프래그먼트를 제거해 사용하고, 비-URL QR 원문은 저장하지 않습니다. 기록은 기기 단위 익명 세션에 90일(슬라이딩) 보관하며 언제든 삭제할 수 있습니다.

## 범위

**Phase 1 (서버리스 MVP):** 제품 서술 + 구글 검색 링크, QR 위험 브리핑, 맞춤 QR 생성(URL 한정), 이력 페이지네이션, 한글 UI, 익명 세션.

**Phase 2:** 가격 검색·최저가 비교·크롤링, 헤드리스 브라우저 기반 심층 분석(리다이렉션·가짜 로그인 폼), AI 소스 분석, 로그인과 기기 간 동기화, 아카이브 화면.

## 개발 환경 (구현 시작 후)

> 아직 코드가 없어 실행할 수 없습니다. 아래는 계획된 방식입니다.

- Node.js, Cloudflare `wrangler`. 로컬에서는 `wrangler dev`가 D1·R2·KV를 시뮬레이션하므로 Cloudflare 리소스를 만들지 않아도 시작할 수 있습니다.
- 시크릿은 **`.dev.vars`**(`NAME=value` 형식, git 제외)에 둡니다. 키 값은 저장소에 커밋하거나 화면에 출력하지 않습니다.

```
# .dev.vars (예시: 값은 직접 채웁니다)
EXAONE_API_KEY=
APP_ENV=development
LIMITS_MODE=off        # 개발 모드에서만 앱 한도 해제 (docs/llm-budget.md 10절)
```
